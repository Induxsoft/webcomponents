Mandar al servidor solo lo que cambió

Edite precios, agregue y borre productos: getChanges() lleva la cuenta en vivo de las altas, los cambios (con el valor original) y las bajas. Abajo está el JSON exacto que se enviaría al guardado de CRUD-L o de V12, sin reenviar el catálogo completo.

Código Descripción Línea Costo Precio Activo
0altas (added)
0cambios (modified)
0bajas (deleted)
0 Btamaño del envío (vs. — el catálogo)











  

    
Pruebe

    
    
      
  • Cambie un precio: aparece en cambios con solo el campo cambiado. Regréselo a su valor y desaparece.
    • 
      
  • Agregar producto y escriba un código: la alta nace cuando la fila tiene datos.
    • 
      
  • Borre una fila con el botón o con Ctrl+Supr: va a bajas con su llave. Una alta que se borra no se envía.
    • 
      
  • Guardar simula el envío y llama a AcceptChanges(): el estado actual pasa a ser la base.
    • 
    

  

  

    
API que usa esta página

    
    
      
  • getChanges() → {added:[{index,data}], modified:[{index,data,original}], deleted:[{data}]}.
    • 
      
  • isNew(i) para pintar la fila; AcceptChanges() después de guardar.
    • 
      
  • La base se toma al primer cambio: si nadie edita, no cuesta nada. No toca IsDirty ni backup().
    • 
      
  • Lo que se cambie directo en DataArray[i].x = … no se ve: use UpdateDataMember, como el botón de 5 %.
