Mandar al servidor solo lo que cambió

Se editan precios, se agregan y se borran productos; al guardar, getChanges() entrega tres listas —altas, cambios y bajas— listas para el guardado de CRUD-L o de V12, sin reenviar el catálogo completo.

API que usa esta página (propuesta para F8)

    
    
      
  • Bandera 'changes'. getChanges() devuelve {added, modified, deleted}: filas nuevas, filas cambiadas (con su llave) y filas borradas.
    • 
      
  • AcceptChanges() toma el estado actual como nuevo punto de partida (como backup(), pero también olvida altas y bajas).
    • 
      
  • La llave de cada fila es el atributo key de la tabla.
    •
