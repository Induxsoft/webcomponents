Cuatro temas de fábrica y una paleta a la medida

Hoy cada aplicación arma su tema con control-styles (este sitio lo hace con assets/tema-edittable.js). En 2.0 basta con un atributo: theme="claro|oscuro|jade|libro-mayor", y palette para cambiar colores puntuales sin reescribir CSS.

API que usa esta página (propuesta para F8)

  • Bandera 'theme'. Atributo theme (propiedad Theme) con claro, oscuro, jade o libro-mayor; observado, así que cambiarlo después de cargar se aplica.
  • Atributo palette: JSON con colores puntuales (accent, header…) que se vuelven variables --et-*.
  • Sin theme, el componente se ve como hoy (regla R1); control-styles sigue ganando.

Mientras tanto

  • Sin la bandera, los atributos se ignoran y las cuatro tablas se ven con el estilo de la versión actual.
  • Estas tablas llevan data-tema="propio" para que el sitio no les ponga su tema.
